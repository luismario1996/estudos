box level

os box level são constituídos por height(altura),widht(largura), padding(espaçamento interno), margin(espaçamento externo), outline (uma linha contorno)e border(bordas)

uma das características dos box level são que eles quebram linhas e ocupam toda a largura do html.

abaixo alguns modelos de tag box level : 

     
       <div>
       <h1 - h6 >
       <p>
       <main>
       <header>
       <nav>
       <article>
       <aside>
       <footer>
       <form>
       <video>

box inline level

os box inline level são constituídos por height(altura),widht(largura), padding(espaçamento interno), margin(espaçamento externo), outline (uma linha contorno)e border(bordas)

uma das características dos box inline level são que eles não quebram linhas e nao ocupam toda largura da pagina e sim ficam lado a lado como caixas em filas lado a lado. .
